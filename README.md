# Book of Dogs

A World of Warcraft: Forever addon for the guild **Dog**: a shared book of notable players from other guilds, ranked by guild votes.

## Features
- Right-click any player → **Add to Book of Dogs** with a short note
- Up/down votes (one per character), ranked list, search, right-click an entry to see who voted
- Syncs across guild members with the addon; new entries are also announced in guild chat
- Guild members can't be added; racial slurs are blocked
- Guild master, officers, the main admin and appointed editors can edit and delete entries
- Minimap button (drag to move), `/dogs` to open

## Install
Copy the `BookOfDogs` folder into `World of Warcraft\_forever_\Interface\AddOns\` and fully restart WoW.

## Commands
`/dogs` open · `/dogs add` add target · `/dogs sync` pull the whole book · `/dogs rebuild` reset your copy from the guild · `/dogs status` sync info · `/dogs minimap` show/hide the button
